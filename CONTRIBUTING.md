## Contributing

Before opening a pull request for a new feature or significant change, please open an issue first to discuss the idea. This avoids wasted effort on both sides.

Pull requests that introduce significant new functionality without prior discussion will be closed.

Small, focused pull requests are strongly preferred. If you find yourself touching many files or adding hundreds of lines, that is a sign the scope needs to be discussed first.

Bug fixes and small improvements can go straight to a PR without prior discussion.
